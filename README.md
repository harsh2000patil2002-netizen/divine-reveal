# Divine Reveal

Create a complete, polished, responsive interactive digital Ganpati festival invitation website for my brand FestiveLink.

IMPORTANT:

Build the entire website in ONE generation.

Do not create unnecessary pages, dashboards, authentication, backend, database, or admin panel.

Keep the implementation lightweight and suitable for free-tier/limited AI coding credits.

Prioritize the visual experience, animations, mobile responsiveness, and invitation flow.

This is a SAMPLE CUSTOMER INVITATION, not the FestiveLink company homepage.

Use the uploaded Ganpati image as the main hero/visual reference. Do not replace it with a random image.

The website must work beautifully on mobile because the invitation will primarily be opened from Instagram/WhatsApp links.

BRAND

Brand name: FestiveLink

Tagline:
Not just an invitation. An experience.

Design direction:
Premium + elegant + spiritual + modern Indian festive aesthetic.

Avoid:

Generic wedding-template appearance

Excessive gradients

Overcrowded decorations

Cheap-looking animations

Too much text

Generic stock-dashboard UI

The website should feel like a luxury digital invitation that comes alive when opened.

1. INITIAL SCREEN — INVITATION REVEAL

When the link is opened, do NOT immediately show the complete invitation.

Show a full-screen immersive opening screen.

Background:

Warm dark brown / deep earthy tone

Very subtle bamboo/natural texture inspired by the uploaded Ganpati image

Soft warm glow

Tiny floating golden particles

Center:
A beautiful glowing diya.

Text:

॥ श्री गणेशाय नमः ॥

Then:

A divine celebration awaits...

Button:

TAP TO REVEAL

The button should have a subtle breathing/glow animation.

IMPORTANT:
Do not autoplay music before interaction.

2. TAP REVEAL ANIMATION

When the user taps TAP TO REVEAL:

Create a smooth cinematic sequence:

Diya flame becomes brighter.

Warm golden light expands outward.

Tiny flower petals and golden particles appear.

A subtle rangoli pattern draws itself around the center.

The uploaded Ganpati image smoothly fades/zooms into view.

The invitation title appears with a soft staggered animation.

Keep this animation elegant and fast enough for mobile.

Do not make it flashy or excessive.

After the animation, the user reaches the main invitation.

3. HERO SECTION

Use the uploaded Ganpati image prominently.

Create a premium rounded image/card treatment inspired by the uploaded image:

Rounded corners

Subtle golden border

Soft shadow/glow

Warm lighting

Natural bamboo/leaf/flower visual language

Overlay or place below the image:

गणपति बप्पा मोरया 🙏

Ganpati Chaturthi 2026

Then:

With the blessings of Lord Ganesha,
we warmly invite you to celebrate
the arrival of Bappa with us.

Add a small animated downward scroll indicator.

4. EVENT DETAILS

Create a clean elegant section titled:

Join Us For The Celebration

Use three beautiful cards:

📅 DATE

27 August 2026

🕰 TIME

6:30 PM onwards

📍 VENUE

FestiveLink Celebration Hall
Pune, Maharashtra

Use elegant icons and subtle hover/tap animations.

Add two buttons:

VIEW LOCATION

ADD TO CALENDAR

These can use placeholder functionality for the demo.

5. PERSONALIZED FAMILY SECTION

This section demonstrates an important FestiveLink feature: customers can add their own photos.

Title:

Celebrating Bappa Together ❤️

Create a beautiful photo frame/card containing a SAMPLE FAMILY PHOTO PLACEHOLDER.

Use a placeholder image area that clearly looks like a customer-uploaded photograph.

Text:

The [Family Name] Family

Your presence and blessings will make this celebration even more special.

Design the photo like a premium printed photograph:

Rounded corners

Decorative border

Subtle flower/petal elements

Gentle floating animation

IMPORTANT:
Structure this component so the sample image can easily be replaced later with a customer's uploaded photo.

6. PHOTO MEMORIES

Create a section:

Moments With Bappa

Show 5–6 sample image cards in a beautiful responsive layout.

Use a combination of:

Large featured image

Small overlapping photographs

Polaroid-style cards

Rounded cards

Add subtle scroll reveal animations.

Do NOT make it look like a generic photo gallery.

It should feel like a collection of memories inside an invitation.

7. VIDEO SECTION

Create a premium video section titled:

A Little Celebration From Our Family

Show a stylish video placeholder/card.

The design should support a customer-provided video later.

For the demo:

Use a visual video thumbnail

Large play button

Rounded corners

Elegant golden border

Small "Watch Message" label

If no actual video is available, clicking play can show a beautiful placeholder/modal saying:

Your family video will appear here.

Structure it so the video source can easily be replaced later.

8. FESTIVE INFORMATION SECTION

Create a visually beautiful section:

The Celebration

Display:

🪔 Ganpati Sthapana
6:30 PM

🙏 Aarti
7:30 PM

🌸 Mahaprasad
8:00 PM

🎶 Bhajan & Celebration
8:30 PM

Use elegant timeline/card styling.

9. INTERACTIVE FESTIVE EFFECTS

Add subtle effects throughout the page:

Floating marigold petals

Tiny golden particles

Very subtle diya glow

Rangoli line animations

Soft scroll-reveal animations

Gentle image zoom/parallax

Occasional floating flower petals

IMPORTANT:
Effects must be lightweight and smooth.

Do NOT overload the page with particles.

Respect mobile performance.

Also respect prefers-reduced-motion by reducing/disabling heavy animations.

10. FINAL INVITATION SECTION

Make the ending emotionally beautiful.

Use a darker warm background with several softly glowing diyas.

Large text:

Your Presence Will Make
This Celebration Complete.

Then:

🙏 गणपति बप्पा मोरया 🙏

Small text:

We can't wait to celebrate with you.

Add a prominent button:

SHARE INVITATION

When clicked, use the Web Share API if available.

Fallback:
Copy the invitation URL to clipboard and show:

Invitation link copied!

11. FESTIVELINK BRAND FOOTER

At the very bottom:

FestiveLink

Not just an invitation. An experience.

Small text:

Made with ❤️ for celebrations

Keep this extremely minimal.

VISUAL DESIGN SYSTEM

Use a premium Indian festive palette:

Deep earthy brown

Warm cream

Saffron/orange

Marigold orange

Subtle antique gold

Dark green accents inspired by leaves

Do not use bright neon colors.

Typography:

Elegant serif/display font for major headings

Clean modern sans-serif for body text

Optional tasteful Devanagari font for Sanskrit/Hindi text

The overall visual hierarchy should feel premium and editorial.

Use generous spacing.

MOBILE-FIRST DESIGN

This is extremely important.

The majority of users will open the invitation on phones.

Requirements:

Perfect mobile layout

Touch-friendly buttons

No horizontal scrolling

Images should crop beautifully

Animations must remain smooth on low-end phones

Text must remain readable

Hero should fit nicely within the mobile viewport

Keep important CTA buttons easy to tap

Also make the desktop version beautiful.

TECHNICAL REQUIREMENTS

Build as a clean modern frontend.

Use:

React

Tailwind CSS

Lightweight animation library only if already available

Lucide icons or another lightweight icon library

Do not add unnecessary dependencies.

Use reusable components for:

Reveal screen

Hero

Event details

Customer photo

Gallery

Video

Schedule

Final CTA

Use placeholder/sample data so the template can later be customized for different customers.

Keep all customer-editable content easy to locate in one configuration/data object if practical:

Family name

Date

Time

Venue

Description

Photos

Video

Event schedule

Do NOT build an admin panel.

IMPORTANT PRODUCT IDEA

This is a FestiveLink template, so design the code/components in a way that the same structure can later be reused for many customers.

The customer should eventually be able to provide:

Their name/family name

Ganpati image

Family photos

Short video

Event date

Event time

Venue

Custom message

The current website should use attractive sample content to demonstrate this experience.

FINAL QUALITY REQUIREMENT

The final result should feel like:

Opening a beautiful physical festival invitation — but brought to life digitally.

The experience should follow:

LINK OPENS
↓
TAP TO REVEAL
↓
DIYA LIGHTS
↓
GANPATI REVEALS
↓
INVITATION APPEARS
↓
EVENT DETAILS
↓
FAMILY PHOTOS
↓
VIDEO
↓
CELEBRATION SCHEDULE
↓
EMOTIONAL FINAL MESSAGE
↓
SHARE INVITATION

Make it visually impressive enough that someone seeing the website in an Instagram Reel immediately understands:

“This isn't a PDF invitation. This is a FestiveLink.”
